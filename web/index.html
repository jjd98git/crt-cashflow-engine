STACR 2026-DNA1 cashflow engine

Reference-pool and reference-tranche cashflows for Freddie Mac STACR REMIC 2026-DNA1 under a prepayment / credit-event scenario, computed by the project's Python engine.

Runs entirely in your browser; nothing is uploaded Decimal arithmetic, deterministic manifest per run Source on GitHub

Engine version and commit appear once the runtime has loaded.

Starting the engine

The engine wheel, its two pure-Python dependencies (openpyxl, et_xmlfile) and the deal data travel inside one JavaScript file from this site, each checked against the SHA-256 in the build manifest before it is used. The Python runtime (Pyodide, about 12 MB) comes from this site, or from the jsdelivr release CDN if this site's copy cannot be reached. First load takes 10-30 seconds depending on the connection; later loads are faster because the browser caches the runtime. If a file fails to load, the message below names its exact URL; diag.html tests every file one at a time.

      Downloads

      The CSV bundle is crt.api.export_csv (seven tables plus manifest.json); the workbook is crt.excel.structure_workbook (engine values with charts; no formulas yet). Both are built in the browser by the same Python code the command line uses.

      PPM tie-out

      The tie-out compares the engine's WAL, principal-window, declining-balance and credit-event-sensitivity figures for all 96 PPM scenarios against the offering memorandum's tables. Running it here takes from about 15 seconds to a couple of minutes depending on the machine, and keeps the engine busy; the page stays responsive.

      The page does no arithmetic: every figure, table and chart value is a string produced by the engine (Python Decimal), and the charts plot display-only copies of those strings. The engine wheel, the deal terms, the PPM tables and the assumptions register are the repository's own files, hashed in the build manifest.
